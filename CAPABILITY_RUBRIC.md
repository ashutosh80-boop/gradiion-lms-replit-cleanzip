# CAPABILITY RUBRIC

## Core Principle

Every GRADIION task must specify:

- what capability it tests
- what evidence it produces
- what counts as acceptable
- what triggers Correction Required
- what resubmission must improve
- how it contributes to future GCP/GCS/Passport records

The rubric exists to prevent the LMS from becoming a completion tracker. It should make every meaningful task traceable to capability evidence.

## Evidence Type Rubrics

### A. Baseline Diagnostic

Tests:

- Clarity
- Communication
- Decision-Making
- Execution
- Professional Presence
- Composure

Purpose:

Establish starting capability profile before training begins.

Approved:

- Provides clear initial evidence across all six domains.
- Shows sufficient self-awareness of pressure patterns.
- Identifies current behavioral weaknesses without overexplaining or deflecting.
- Gives enough detail to establish a useful starting record.

Correction Required:

- Vague diagnosis.
- Avoidance of weakness.
- Emotional justification instead of evidence.
- No clear pressure pattern.
- No usable baseline for later comparison.

Resubmission Must Fix:

- Name the pressure pattern more specifically.
- Clarify observable behavior under pressure.
- Remove unsupported explanation.
- Provide evidence that can be compared against future work.

GCP/GCS/Passport Contribution:

- Seeds the baseline capability record.
- Establishes early domain scores.
- Creates comparison data for later verification.

### B. Decision Check

Tests:

- Clarity
- Decision-Making
- Composure

Purpose:

Assess whether the student can recognize pressure patterns and select the correct correction.

Approved:

- Identifies the correct pressure pattern.
- Selects a correction that matches the scenario.
- Avoids impulsive or emotionally justified choices.
- Demonstrates stable reasoning under constraint.

Correction Required:

- Weak decision.
- Misread pressure condition.
- Chosen correction does not match the problem.
- Overexplaining instead of deciding.
- No clear ownership of the selected action.

Resubmission Must Fix:

- Select a clearer decision.
- Explain the pressure condition accurately.
- Match the correction to the observed weakness.
- Remove irrelevant justification.

GCP/GCS/Passport Contribution:

- Feeds Decision-Making, Clarity, and Composure evidence.
- Supports pattern detection for repeated weak decisions.

### C. Scenario Judgment Drill

Tests:

- Clarity
- Decision-Making
- Composure
- Communication

Purpose:

Assess judgment under a realistic pressure condition.

Approved:

- Recognizes the pressure condition.
- Communicates judgment clearly.
- Selects a practical correction.
- Maintains composure in the response.
- Shows enough reasoning to prove the judgment was not random.

Correction Required:

- Vague diagnosis.
- Weak decision.
- Communication drift.
- Emotional justification.
- No correction.
- Theory-only response.

Resubmission Must Fix:

- Identify the actual pressure condition.
- State the decision directly.
- Provide a specific correction.
- Reduce explanation that does not support the decision.

GCP/GCS/Passport Contribution:

- Creates applied judgment evidence.
- Supports domain scoring for pressure-based decision quality.

### D. GCP Video Response

Tests:

- Clarity
- Communication
- Professional Presence
- Composure

Purpose:

Assess live verbal response, structured thought, composure, and presence under attention.

Approved:

- Response is structured and direct.
- Student maintains professional presence.
- Communication remains steady.
- Thought process is clear under attention.
- Response answers the prompt without hiding behind polish.

Correction Required:

- Overexplaining.
- Communication drift.
- Composure break.
- Avoidance.
- Polished theory without evidence.
- Unclear ownership.

Resubmission Must Fix:

- Reduce verbal clutter.
- Answer the prompt directly.
- Show steadier presence.
- Provide specific evidence or correction logic.

GCP/GCS/Passport Contribution:

- Produces high-value GCP evidence.
- Supports Communication, Professional Presence, Clarity, and Composure scoring.
- May become Passport evidence after review and verification.

### E. GCP Audio Response

Tests:

- Clarity
- Communication
- Composure

Purpose:

Assess verbal structure and steadiness without visual cues.

Approved:

- Audio response is clear and organized.
- Student communicates the correction logic without visual support.
- Tone remains steady.
- Response stays on prompt.

Correction Required:

- Rambling.
- Unclear sequence.
- Emotional justification.
- No correction.
- Communication drift.

Resubmission Must Fix:

- Use a clearer verbal structure.
- State the diagnosis and correction plainly.
- Remove unsupported explanation.
- Improve steadiness.

GCP/GCS/Passport Contribution:

- Adds verbal evidence where visual presence is not assessed.
- Supports Communication, Clarity, and Composure scoring.

### F. GCP Written Response

Tests:

- Clarity
- Decision-Making
- Execution

Purpose:

Assess diagnostic precision and correction logic.

Approved:

- Identifies the friction pattern clearly.
- Defines the decision or correction.
- Shows an execution step.
- Uses concise evidence rather than abstract theory.

Correction Required:

- Vague diagnosis.
- No clear correction.
- Weak decision.
- Execution vagueness.
- Theory-only response.

Resubmission Must Fix:

- Make the diagnosis specific.
- State the correction.
- Add an observable execution step.
- Remove generic language.

GCP/GCS/Passport Contribution:

- Provides written capability evidence.
- Supports Clarity, Decision-Making, and Execution scoring.

### G. Field Application

Tests:

- Execution
- Decision-Making
- Clarity

Purpose:

Assess whether the student can identify a real-world application target.

Approved:

- Names a real situation.
- Defines the pressure present.
- Identifies the behavior that weakens.
- States a correction that can be applied.

Correction Required:

- No specific pressure situation.
- No clear correction.
- No field application.
- Execution vagueness.
- Avoidance of ownership.

Resubmission Must Fix:

- Specify the real situation.
- Name the pressure.
- Identify the weakening behavior.
- Define the correction in practical terms.

GCP/GCS/Passport Contribution:

- Connects learning evidence to real-world application.
- Supports Execution, Decision-Making, and Clarity records.

### H. Field Execution Report

Tests:

- Execution
- Clarity
- Composure
- Decision-Making

Purpose:

Assess whether the student actually applied the correction and can report what held, failed, or changed.

Approved:

- Reports what was attempted.
- Describes what happened under pressure.
- Explains what held, failed, or changed.
- Identifies the next correction if needed.
- Shows ownership of execution.

Correction Required:

- No evidence.
- Polished theory without evidence.
- Unclear execution step.
- Avoidance.
- Emotional justification.
- No correction after failure.

Resubmission Must Fix:

- Provide concrete evidence of action.
- Clarify the execution step.
- State what changed or failed.
- Define a next correction.

GCP/GCS/Passport Contribution:

- Creates field evidence.
- Supports Execution-heavy scoring.
- Can strengthen Passport readiness when reviewed and verified.

### I. Correction Resubmission

Tests:

- Clarity
- Execution
- Communication
- Composure

Purpose:

Assess whether the student corrected the weakness identified in review.

Approved:

- Directly addresses the correction note.
- Improves the original weakness.
- Communicates the revision clearly.
- Shows composure and ownership.
- Avoids defensiveness.

Correction Required:

- Resubmission does not address the correction.
- Student defends the original weak response.
- Unclear ownership.
- Same failure pattern repeats.
- Communication drift.

Resubmission Must Fix:

- Respond directly to the correction note.
- Show what changed.
- Provide corrected evidence.
- Remove defensive explanation.

GCP/GCS/Passport Contribution:

- Creates correction history.
- Supports correction density analysis.
- Helps determine whether weakness was resolved.

### J. Capstone Response

Tests:

- Clarity
- Communication
- Decision-Making
- Execution
- Professional Presence
- Composure

Purpose:

Final proof event across all six domains.

Approved:

- Demonstrates all six domains under pressure.
- Shows clear diagnosis, decision, communication, execution logic, presence, and composure.
- Resolves the prompt with evidence.
- Avoids theory-only performance.
- Meets capstone-specific proof requirements.

Correction Required:

- Any major domain gap.
- Weak decision.
- No execution proof.
- Communication drift.
- Composure break.
- No evidence.
- Avoidance of responsibility.

Resubmission Must Fix:

- Address the failed domain.
- Provide specific evidence.
- Correct weak decision or execution logic.
- Show improved composure and ownership.

GCP/GCS/Passport Contribution:

- Becomes major capstone evidence.
- Can heavily influence final GCS interpretation.
- Can support Capability Passport issuance only if approved or verified.

## Approval Criteria

Across all evidence types, approval means the submission is specific, relevant, owned by the student, and useful as capability evidence.

Evidence is Approved when it:

- addresses the prompt directly
- maps to the intended capability domains
- gives enough detail for review
- includes a usable correction or decision where required
- avoids vague, defensive, or theory-only responses
- can be stored in the GCP record

## Correction Required Criteria

Correction Required applies when a submission has potential but is not yet acceptable as capability evidence.

Common triggers:

- vague answer
- no specific pressure situation
- no clear correction
- overexplaining
- avoiding responsibility
- weak decision
- no field application
- polished theory without evidence
- emotional justification
- unclear execution step

## Resubmission Criteria

Resubmissions must correct the specific weakness identified in review.

Every resubmission should:

- address the correction note directly
- improve the failed capability domain
- provide clearer evidence
- show ownership
- reduce explanation that does not support the correction
- become reviewable as a new evidence version

## Verification Criteria

Evidence becomes Verified later when it is:

- reviewed by admin/AI
- correction resolved if required
- timestamped
- linked to capability domain
- accepted into GCP record

Verified evidence should be eligible for GCS interpretation and future Capability Passport records.

## AI Marking Readiness

Future AI marking should output:

- status recommendation
- capability domain scores
- failure tags
- correction note
- resubmission instruction
- human review flag

AI marking should not be treated as final authority until the review model is approved. It should generate structured review assistance for human or institutional verification.

## Failure Mode Tags

Reusable failure tags:

- vague diagnosis
- overexplaining
- no correction
- weak decision
- avoidance
- emotional justification
- execution vagueness
- composure break
- communication drift
- no evidence
- theory-only response
- unclear ownership

## Module Pass Criteria

A module should not be considered passed unless:

- required evidence items are submitted
- no unresolved Correction Required items remain
- required resubmissions are completed
- capability evidence is accepted into the GCP record

Completion alone is not enough. Module passage requires acceptable evidence.
